Uploads

Every spreadsheet upload in one place. Pick what you are uploading — the matching screen and format appear below. Uploads always go into the company selected in Working on.

Bulk upload employees (Excel)

Upload an .xlsx/.xls/.csv file with one row per employee for the selected company. Name of the Worker, Designation, Basic Salary, Skilled Category, Category, Department, Working Place, UAN No, ESIC No, Bank Name, Bank Account No, Bank IFSC No and Date of Joining are mandatory — rows missing any of these are rejected and listed below. Employee No is optional; if left blank one is generated automatically. Matching to an existing employee is done by UAN No (the unique key) — if an uploaded UAN No matches an existing employee, that employee's record is updated.
Client Name check: if the sheet has a Client Name column, only rows whose Client Name matches the company you are uploading into are accepted — rows belonging to another client company are rejected and listed below.

Columns recognised: Employee No, Name of the Worker, Designation, Mobile No, Basic Salary, Mode of Salary, Skilled Category, Category, Department, Working Place, Grouping of Skilled, Father Name, UAN No, ESIC No, Client Name, Bank Name, Bank Account No, Bank IFSC No, Date of Joining, Earned Leave Provided, Paid Leave Provided, Reference1–Reference10.

Upload monthly attendance (Excel)

Pick the month the sheet belongs to, then choose the file. Rows are matched to employees already on file by Employee No — anything that does not match is skipped. Uploaded figures land in the Monthly Attendance table, where you can check them and save.

Format: one row per employee, with these columns — Employee No (required, used to match), Days Paid, LOP Days, Overtime, Variable Pay, Leave Encashment, Other Deduction, Pay Date (DD-MM-YYYY). Basic pay is never uploaded here; it stays as set in the Employee Master.

Monthly Attendance

Pick a month, then either upload a spreadsheet or fill the table directly. Only variable figures live here — basic pay stays as set in the Employee Master.

Spreadsheet columns recognised: Employee No, Days Paid, LOP Days, Overtime, Variable Pay, Leave Encashment, Other Deduction, Pay Date. Rows are matched to employees by Employee No — anything not on file is skipped.
